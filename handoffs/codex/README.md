# המסע אל אבא — חומרי הפקה

זהו מאגר עבודה לספר הקומיקס, עדיין לא גרסה סופית. הסיפור והעורך המקורי נמצאים ב־`index.html`. קובצי התמונות הנבחרים נמצאים ב־`art/`, בשמות שהעורך מצפה להם. אין לשנות שמות אלה. פתחו את הקובץ `index.html` בדפדפן לאחר שיבוט המאגר; אפשר גם להגיש אותו מקומית עם `python3 -m http.server 8000` ולפתוח `http://localhost:8000/`.

- `manifest.json` — רשימת האיורים, תיאורי הסצנות, מידות היעד, אזורים בטוחים והנחיות לריווח הכיתוב.
- `art/` — בחירת הטיוטות הנוכחית לתצוגה (105 קבצים, כולל שכבות שקופות).
- `drafts/` — גרסאות מקור וחלופות ששימשו בהפקה; `selection.json` מציין מה נבחר לכל תמונה.
- `characters/`, `character-bible.json` — דפי הדמויות ותיאורי הזהות.
- `ref/` — חומרי התייחסות, ובכללם תמונה משפחתית פרטית. יש לשמור את המאגר פרטי.
- `production-brief-he.md` — ערכת ההפקה שסופקה; `production-state.json` ו־`inventory.json` מתעדים בדיקות ומגבלות קיימות.
- `CLAUDE.md` — הנחיות מסירה לתפקיד עיצוב הדפים.

להרצת בדיקת שלמות: `python3 scripts/check_assets.py`. הבדיקה אינה מחליפה בקרה חזותית בדפדפן או בדיקת התאמה לסיפור.

הערה: החבילה כוללת טיוטות, לא תמונות שאושרו סופית. בעיות ידועות כוללות חיתוך ומרחב לכיתוב, רציפות דמויות ומיקום, הילות שקיפות בשכבות עמודים 4 ו־7, והתאמות מידות. דוח מפורט ב־`production-state.json`.

- `archive/` — קובץ הצופה המקורי ודוחות מצב קודמים לשימור; הדוחות עלולים להיות מיושנים.
- `proof/` — סטוריבורד טיוטה ב־PDF וסקריפט נייד ליצירתו מחדש.

`inventory.json` הוא צילום מצב ישן; לבדיקה עדכנית יש להריץ את הסקריפט. הוא מדווח על חריגות מידות אך קוד היציאה שלו מעיד על חסר בקבצים בלבד.
