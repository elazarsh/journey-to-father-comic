# תצוגת סצנות — טיוטה

comic-storyboard-preview.pdf הוא קובץ תצוגה נוח של איורים וקטעי טקסט בעברית. זה אינו עיצוב הקומיקס המקורי או הסופי. ליצירה מחדש, מסביבת Python שבה מותקנים PyMuPDF ו־Pillow, הריצו `python3 proof/create_proof.py` משורש המאגר. הסקריפט קורא את art ואת manifest ומייצר מחדש את קובץ ה־PDF ואת תמונת העמוד הראשון. הגופן DejaVu Sans מצורף לצורך תצוגת עברית.
