# מפת הפרויקט — המסע אל אבא

מאגר עבודה פרטי לספר קומיקס משפחתי. הקבצים הם טיוטות להמשך הפקה ובקרה, ולא ספר גמור. התמונה המשפחתית שב־`ref/` מחייבת שמירה על פרטיות המאגר.

## מאיפה מתחילים

1. קוראים את `production-brief-he.md`, את הוראות העיצוב ב־`CLAUDE.md`, ואת המפרט המפורט ב־`manifest.json`. ההנחיה העדכנית של בעל הפרויקט היא להמשיך באופן עצמאי, עם בקרה פנימית, בלי לבקש אישור לכל תמונה או עמוד.
2. פותחים את הצופה `index.html` דרך שרת מקומי משורש המאגר:

   ```sh
   python3 -m http.server 8000
   ```

   פותחים בדפדפן `http://localhost:8000/`. הקובץ מכיל את הטקסטים, עמודי הסיפור, סידור הפאנלים וכלי העריכה. `art/` חייבת להיות לצדו. במחשב ובמכשיר נייד מתקבלת פריסה שונה; שכבות צפות מוסתרות בפריסת המובייל. בדפדפנים מסוימים פתיחה ישירה של `index.html` עשויה לעבוד, אך שרת מקומי הוא דרך הבדיקה המועדפת.
3. בודקים את הקבצים עם `python3 scripts/check_assets.py`. מומלץ להתקין Pillow כדי לקבל גם דיווח על מידות ושקיפות. הסקריפט מחזיר קוד שגיאה על קבצים חסרים; דיווח על מידות חריגות אינו גורם בפני עצמו לכישלון, ובדיקה אוטומטית זו אינה מאשרת מראה, התאמת חיתוך או איכות שקיפות.

## מבנה המאגר

| נתיב | תפקיד |
| --- | --- |
| `index.html` | צופה ועורך הקומיקס הנוכחי, כולל הטקסט בשפות והעמוד הראשון שתוקן כטיוטה. אין לראות בפריסה הקיימת עיצוב סופי. |
| `art/` | האיור הנבחר לכל פאנל ושכבה. 105 קבצים, ובהם 6 שכבות שקופות, ל־24 עמודים. השמות `pNN-x.png` ו־`pNN-n1.png` הם חוזה הטעינה של הצופה ואין לשנותם ללא עדכון הצופה. |
| `drafts/page01/` עד `drafts/page24/` | המקורות והניסיונות הקודמים לכל עמוד; סיומות `-vNN` מבדילות בין גרסאות. אין להניח שהמספר הגבוה הוא הנבחר או התקין. |
| `selection.json` | מיפוי כל קובץ ב־`art/` לנתיב הטיוטה שממנו נבחר. אם מחליפים תמונה, יש לעדכן גם את המיפוי ולשמור את הגרסה הקודמת. |
| `manifest.json` | מפרט היצירה לכל סצנה: מיקום בסיפור, דמויות, פרומפט, מידת יעד, יחסי הצגה למחשב ולטלפון, אזור בטוח ומקום לכיתוב. תוכן המפרט אינו מוכיח שהאיור שנבחר עומד בו. |
| `characters/` | דפי התייחסות לדמויות ובחלקם קובצי פרומפט. דף `lebParents` מכיל שתי דמויות. |
| `character-bible.json` | תיאורי דמויות והנחיות עקביות לעבודה על תמונות חדשות. |
| `ref/` | צילום הסבא ושתי דוגמאות לסגנון. קבצים אלו פרטיים ואינם מיועדים לפרסום פומבי. |
| `production-brief-he.md` | ערכת ההפקה המקורית שסופקה. בקשת המשתמש להמשיך ללא אישורים מחליפה את דרישת האישור לכל דמות או עמוד שבמסמך המקורי. |
| `production-state.json` | רישום נקודתי של בחירות, ניסיונות ובעיות ידועות. יש לעדכן עם כל שינוי ולוודא שכל רשומה עדיין תקפה. |
| `inventory.json` | צילום מצב היסטורי של בדיקת מלאי, לא מקור אמת למצב הנוכחי. |
| `scripts/` | בדיקת המלאי `check_assets.py`; אופן השימוש לעיל. |
| `proof/` | קובץ PDF של סטוריבורד טיוטה, תמונת עמוד לדוגמה, סקריפט יצירה וגופן. זהו סידור סקירה של תמונות וקטעי טקסט, ואינו עיצוב הקומיקס שבצופה. ראו `proof/README.md`. |
| `proof/fonts/` | הגופן המשמש לסקיצה ורישיון הגופן. |
| `archive/` | קובץ הצופה המקורי לפני שינויים ודוחות ישנים לשימור. דוחות המצב בתיקייה מיושנים ועלולים לסתור את המצב הנוכחי. |
| `CLAUDE.md` | מסמך המסירה לקלוד: אחריות על עיצוב עמודים, חיתוך וטיפוגרפיה. זה אינו אישור שקלוד קיבל את המשימה או החל לעבוד. |
| `README.md` | סקירה קצרה והוראות פתיחה. |
| `.git/` | היסטוריית העבודה המקומית; יעד מרוחק נקבע בנפרד. |

ליצירת סטוריבורד מחדש משורש המאגר, אחרי התקנת `PyMuPDF` ו־`Pillow`, מריצים `python3 proof/create_proof.py`. פעולה זו מייצרת מחדש את קובץ ה־PDF ואת תמונת העמוד הראשון שבתיקיית `proof/`; היא אינה מייצאת את פריסת הצופה.

## חלוקת עבודה ותוצרים

Codex אחראי ליצירת תמונות נפרדות ולתיקונן. התמונות עצמן אמורות להיות בלי טקסט, בועות או מסגרות; הלטרינג, החיתוך, סדר הפאנלים והעיצוב נעשים בצופה. Claude מיועד להוביל את עיצוב העמודים בהתבסס על המסמך `CLAUDE.md`. יש לשמר את השינויים בעיצוב בקבצים משוחזרים במאגר, ולא להסתמך רק על נתונים שנשמרים בדפדפן מקומי.

התוצרים הקיימים הם קובצי תמונה נפרדים, דפי דמויות, מפרט, טיוטת צופה וסטוריבורד PDF. הם אינם קובץ סופי מאושר לדפוס או פרויקט עימוד סופי.

## קריטריוני בקרה לפני מסירה סופית

- **שלמות:** כל קובץ ברשימת `manifest.json` קיים ב־`art/`, כל בחירה ב־`selection.json` מצביעה לקובץ קיים ותואמת לתמונה הנבחרת, וכל הנכסים נטענים בדפדפן.
- **תוכן ועקביות:** כל סצנה מציגה את האירוע והדמויות שנקבעו; זהות הדמויות, לבושן, מראה האונייה, זמן היום ורצף העלילה נשמרים בין הפאנלים. יש לבדוק דיוק של נמל חיפה והתקופה, ולהבחין בבירור בין האם לאישה המסתתרת.
- **קומפוזיציה:** פנים, ידיים ואביזרים חשובים נשארים גלויים בחיתוך מחשב וטלפון, וכן בזמן תזוזה/זום של הצופה. לתמונות יש שטח פנוי לכיתוב ואין עליהן טקסט מובנה.
- **עיצוב וקריאות:** סדר הקריאה נכון לעברית ולגרסה האנגלית; בועות וכיתובים אינם מסתירים פנים או חורגים מהמסך. יש לבדוק את כל העמודים בגדלים שונים, עם ובלי תנועה, ולתעד באילו גדלים נבדקו.
- **שכבות ומידות:** שקיפות אמיתית עם שוליים נקיים, בלי הילות שנראות על רקעים שונים. יש לבדוק יחס תמונה וממדים מול המפרט; הבדל במספר הפיקסלים לבדו אינו מוכיח בעיית חיתוך, אך יחס שונה מחייב בדיקה חזותית.
- **פרטיות ושחזור:** חומרים משפחתיים נשמרים ביעד פרטי. יש לתעד מה נבדק, מה תוקן ומה טרם נבדק, ולוודא שאדם אחר יכול לפתוח ולערוך את התוצרים.

## ידוע וטרם ידוע

בדיקה קודמת באמצעות Playwright טענה את 24 עמודי הצופה ו־105 תמונות במידות תצוגה של 1200 ו־390 פיקסלים, בלי שגיאות JavaScript; זו אינה בדיקה חזותית מלאה של כל העמודים. נעשתה בדיקה חזותית ותיקון טיוטה לעמוד 1 בלבד. שאר העמודים, חיתוכים דינמיים, תצוגת אנגלית וגדלים נוספים עדיין זקוקים לבדיקה ותיעוד.

הבדיקה האוטומטית שבוצעה לאחרונה מצאה שכל 105 הקבצים קיימים, ו־41 תמונות או שכבות במידות שונות ממידת היעד. חלק מההבדלים הם ברזולוציה בלבד וחלקם ביחס התמונה. תוצאה זו משתנה עם כל החלפת איור ויש להריץ את הבדיקה מחדש. לשכבות השחפים בעמודים 4 ו־7 דווחו הילות בניסיונות יצירה; יש לבחון את הגרסאות הנבחרות על רקעים שונים לפני החלטה. כמו כן, הנוף ההיסטורי, עקביות הפנים וההבחנה בין דמויות אינם מאומתים באופן מלא. פרטים לכל עמוד מופיעים ב־`production-state.json`.
