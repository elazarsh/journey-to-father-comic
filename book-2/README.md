# ספר 2: המשך הסיפור של באבא (1946)

הספר השני בסדרה "הגיבור שלי". הוא ממשיך בדיוק מהמקום שבו נגמר הספר הראשון ("ועל מה אספר לכם בשבוע הבא?"): עמנואל בן כמעט 9 בשבועות ובחודשים הראשונים שלו בארץ.

## מה יש כאן
| תיקייה | מה בתוכה |
|---|---|
| `sources/originals/` | ארבעת הפרקים של באבא כפי שהתקבלו (baba_4 עד baba_7, קובצי Word) |
| `sources/text/` | אותו טקסט כקובץ טקסט, לחיפוש ולציטוט. לא נערך |
| `research/` | המחקר: חילוץ רגעים, דמויות וציר זמן, ניתוח סיפורי, הצעות עלילה, שאלות למשפחה |
| `script/` | התסריט (טבלת עמודים) ייכתב כאן אחרי שתבחרו כיוון עלילה |

## איפה אנחנו (שלבי העבודה של הסקיל)

## מאגר
הספר יושב כרגע כתת־תיקייה במאגר הפרטי של הספר הראשון, כדי להשתמש באותו צופה, באותם כלים ובאותם גיליונות דמות.
הסקיל ממליץ על מאגר פרטי נפרד לכל ספר. אם תרצו, אפשר לפתוח מאגר `journey-to-father-comic-2` (או שם אחר) ולהעביר לשם את התיקייה הזו כמו שהיא.
האתר הציבורי של ספר 2 ייבנה, כמו בספר הראשון, רק מהקבצים לקריאה, בלי החומרים שכאן.
