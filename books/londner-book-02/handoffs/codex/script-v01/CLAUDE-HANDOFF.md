# טיוטת ספר 2, מסירה מ־Codex לקלוד

לבקשת המשתמש, מצורף כל מה שהוכן עד כה. מכאן קלוד מוביל את ספר 2; אין כאן אישור משפחתי סופי של התסריט ואין התחלת איור לספר הזה.

64 עמודי סיפור, 197 משבצות, עברית ואנגלית, סקיצת HTML, מקור נתונים, קוד בנייה, תמלול מקורות מלא, מפת משפחה וגילים ורשומת ניסוחים.

פתיחה: הגעה ב־1925 והחלבה, כתשובה לסיום ספר 1 על האונייה. סוף: גנבת הסוסים בלי פתרון, כדי להשאיר את הסיוע ואסתר לספר 3.

נקודת כניסה: book2-reader.html. לבנייה: python build.py, ואז node verify_pagination.js. קראו editorial-review.md, chronology-and-omissions.md, bereavement-direction.md ו-family-continuity.md.

הבהרות עיקריות: בלטשע היא אחות חוה ושמעון הוא בעלה, לא שמעון אח יצחק. אליהו בן דוד. אל תסיקו שדוד חנצינסקי הוא ״דוד״ במשפחה רק מן השם. שנת קניית המשק, סדר מעברי הבתים וכרונולוגיית אורה אינם מוכרעים. 650 לירות פיצויים אינן מלוא מחיר המשק 1800. ראובן ומשפחתו אכן הגיעו; גורל ניסיון הרשל לפני המלחמה אינו מוכרע.
