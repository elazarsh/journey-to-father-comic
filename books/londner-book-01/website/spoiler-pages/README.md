# עמודי ספוילר לאתר

חמישה עמודים שלמים מהספר (לאורך, 1000 פיקסלים רוחב), שנבחרו כדי לתת חוויית קומיקס בלי לגלות את הסוף:
1. `page-01.webp`: הפתיחה, סבא כותב במחברת לילדים ולנכדים.
2. `page-05.webp`: היום הראשון בחדר והסוכרייה על האות א׳.
3. `page-11.webp`: הבדיחה על הבלקאן והמרפסות.
4. `page-24.webp`: מפת הלוויין, לאן הלך כל אחד מהילדים.
5. `page-35.webp`: "יצחק לונדנר, אתה תשמור!" (נעצר לפני הלילה על הגשר).
להציג כגלריה (קורא עמוד אחד בכל פעם, החלקה בטלפון), עם הזמנה בסוף: "רוצים לדעת מה קרה על הגשר? הזמינו את הספר".
